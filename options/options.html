Embedding model

Empty uses the provider above (Gemini's gemini-embedding-001). For a local model, an OpenAI-compatible address such as http://localhost:11434/v1 (Ollama) or http://localhost:1234/v1 (LM Studio).

Empty on Gemini uses gemini-embedding-001 and gemini-embedding-2, each with its own free quota. A local server needs a model name, e.g. nomic-embed-text.

Only needed for another service. The key above is never sent to a different address.

Embedding requests per model per day (they reset at midnight Pacific time). 0 picks the default: 1,000 on Gemini's free tier, none elsewhere. -1 turns the limit off, e.g. for a paid key. New articles stop at 85% of it, so questions about embedded articles keep working.

Passages scoring below this (cosine, 0 to 1) are ignored, so an unrelated question adds nothing. 0 picks the default: 0.55 for gemini-embedding-001, none for other models (not yet measured for them). -1 turns it off. To calibrate a model, run test/semantic-check.mjs with a related and an unrelated question and set it between the two top scores.

Some models (nomic, e5, bge) expect these prefixes and rank worse without them. Changing the model or the passage prefix embeds articles again.
